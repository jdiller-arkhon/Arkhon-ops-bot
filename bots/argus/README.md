# Argus bot

Reserved for the Argus bot (built in step 3 of the Arkhon bots plan). Follow the conventions in the
root `CLAUDE.md`: a `@arkhon/argus-bot` package, `Argus*` Prisma models mapped to `argus_*` tables,
commands auto-loaded from `src/commands`, and an `argus` service in `docker-compose.yml`.

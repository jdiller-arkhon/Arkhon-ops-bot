# Certa bot

Reserved for the Certa bot (built in step 2 of the Arkhon bots plan). Follow the conventions in the
root `CLAUDE.md`: a `@arkhon/certa-bot` package, `Certa*` Prisma models mapped to `certa_*` tables,
commands auto-loaded from `src/commands`, and a `certa` service in `docker-compose.yml`.
